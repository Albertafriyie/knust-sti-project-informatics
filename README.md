# Project Overview & Abstract

This repository hosts a fully reproducible computational pipeline designed to analyze cross-sectional public health dynamics regarding Sexually Transmitted Infections (STIs) within higher education demographics.
Using an anonymized dataset of 333 student survey responses from Kwame Nkrumah University of Science and Technology (KNUST) (`group17_clean.csv), this project bridges clinical knowledge extraction with predictive analytics and data base normalization.
